# 生活管理面板 (Life Panel)

一个 Obsidian 插件，将月日历、周日历、任务、打卡、番茄钟、灵感、复盘、统计一站式集成到侧边栏面板。

## 功能

### 月日历
- 月度网格视图，点击日期切换
- 每天显示任务完成率、打卡完成率、是否有复盘（活力三环）
- 上一月/下一月导航

### 周日历
- 7 天垂直列表，每天一行
- 左栏日期，中栏任务，右栏打卡
- 任务支持：复选框、优先级、紧急/重要标记、时间、类型标签
- 打卡按习惯类型分组，按周几配置显示
- 点击任务描述编辑单个任务
- 点击 + 添加任务
- 「显示今天」按钮只显示今天

### 番茄钟
- 25/5 倒计时（可配置）
- 关联当日任务，专注完成自动记录到任务
- 停止/暂停时也记录已专注的时间
- 左右两栏布局：番茄钟 + 昨天写的今天的重点

### 每日灵感
- 快速记录灵感，带时间戳
- 支持标签

### 每日复盘
- 可配置的复盘问题
- 自动记录到 daily note

### 统计看板
- 本周打卡、本周任务、本周专注、本月打卡
- 简约四宫格

### 最近文件
- 最近修改/创建的文件列表

## 配置

### 配置文件
配置文件位于 `<vault>/LifePanel/config.md`，用 Markdown 表格管理打卡习惯：

```markdown
## 打卡习惯

| 名称 | 图标 | 类型 | 周目标 | 打卡日 | 开始日期 | 结束日期 |
|------|------|------|--------|--------|----------|----------|
| 久坐活动 | 🪑 | 健康 | 7 | 一二三四五六日 | | |
| 有氧运动 | 🏃 | 运动 | 3 | 一三四五六 | | |
| 读书 | 📚 | 学习 | 7 | 一二三四五六日 | | |
```

- **打卡日**：用「一二三四五六日」组合，留空=每天
- **类型**：健康（红）、学习（绿）、工作（蓝）、生活（黄）、运动（橙）
- 修改后运行命令「生活面板: 重新加载配置」即可生效

### 设置面板
- 根文件夹（默认 `LifePanel`）
- 专注时长 / 休息时长
- 每日复盘问题
- 习惯管理（添加、编辑、归档、删除）
- 主题（跟随 Obsidian / 浅色 / 深色）

## 使用

1. 在 Obsidian 设置 → 第三方插件中启用「生活管理面板」
2. 点击左侧栏图标或运行命令「生活面板: 打开/关闭面板」
3. 全屏模式：运行命令「生活面板: 全屏打开」

### 数据存储
- Daily note: `<folder>/daily/YYYY-MM-DD.md`
- Weekly note: `<folder>/weekly/YYYY-Www.md`
- Habits log: `<folder>/habits/habits-log.md`（月历格式）
- Config: `<folder>/config.md`

## 模块拖拽排序

每个模块标题栏左侧有拖拽手柄 `⠿`，按住即可拖动调整顺序，松手后自动保存。

## 快捷键

在设置 → 快捷键中搜索「生活面板」绑定：
- 打开/关闭面板
- 全屏打开
- 添加今日任务
- 快速记录灵感
- 打卡

```bash
npm run build # 生产构建
```
